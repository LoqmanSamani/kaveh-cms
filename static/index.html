Hilfe

So funktioniert Kaveh CMS.

Programm anlegen

Auf Neues Programm klicken und die Programmnummer eingeben. Danach öffnet sich das Programmblatt. Alle Eingaben werden automatisch gespeichert – unten rechts steht Gespeichert, sobald alles auf dem Server ist.

Koordinaten

Für X, Y und Z gibt es jeweils den Original- und den Geändert-Wert. Die Differenz (Δ) wird automatisch berechnet.

Fotos markieren

Fotos über Neues Foto hinzufügen hochladen oder ins Fotofeld ziehen. Dann ein Werkzeug wählen (Pfeil, Kreis, Text, Linie), eine Farbe antippen und auf dem Foto ziehen. Mit dem Radierer eine Markierung antippen, um sie zu löschen. Das Originalfoto bleibt immer unverändert.

Drucken & PDF

Drucken (A4) druckt das Programmblatt mit allen Fotos und Markierungen. Für ein PDF im Druckdialog „Als PDF speichern“ wählen. Bild speichern lädt das aktuelle Foto mit Markierungen als Bild herunter.
